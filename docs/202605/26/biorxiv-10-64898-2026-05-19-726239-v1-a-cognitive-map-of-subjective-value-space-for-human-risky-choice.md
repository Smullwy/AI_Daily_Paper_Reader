## 摘要
人们被认为基于选项的主观估值做出选择，这些主观估值将多个属性整合成大脑“价值编码系统”中的一个统一的主观价值信号。这些属性如何转化为主观估值仍不清楚。一个候选者是“认知映射系统”，它有效地表征关系性、多维信息，并被认为能够提供新颖的推断。我们开发了一个风险决策任务，并使用fMRI表明，由奖励概率和金额构成的二维主观价值空间在认知映射系统中既表现为决策向量的网格样表征，也表现为内嗅皮层（EC）和内侧前额叶皮层（mPFC）中的二维“位置”编码。网格样表征的强度与主观价值表征的强度呈正相关，表明认知映射系统和价值编码系统协同工作。这些发现连接了这两个系统，并为大脑如何构建价值提供了一个新框架。

## Abstract
Individuals are thought to make choices based on subjective valuations of options that integrate multiple attributes into a unified subjective value signal in the brains "value coding system." How these attributes are transformed into a subjective valuation remains poorly understood. One candidate is the "cognitive mapping system," which efficiently represents relational, multi-dimensional information and has been proposed to afford novel inferences. We develop a risky decision-making task and use fMRI to show that a two-dimensional (2D) subjective value space of reward probability and amount is represented in the cognitive mapping system as both a grid-like representation of decision vectors and a 2D "positional" code in entorhinal cortex (EC) and medial prefrontal cortex (mPFC). The strength of grid-like and subjective value representations are positively correlated, suggesting the cognitive mapping and value coding systems work in tandem. These findings bridge these systems and support a new framework for how the brain constructs values.
