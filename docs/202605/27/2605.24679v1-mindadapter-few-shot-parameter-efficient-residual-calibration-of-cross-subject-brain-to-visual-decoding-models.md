## 摘要
跨被试大脑到视觉的解码仍然是脑机接口中的一个核心挑战，因为严重的个体间差异导致系统性的被试特异性功能失配。为了解决这个问题，我们提出了MindAdapter，一个用于预训练大脑到视觉解码模型的参数高效小样本校准框架。MindAdapter采用解耦的线性-残差级联对齐范式，通过冻结预训练的显式大脑功能对齐骨干网络（粗）并引入轻量级非线性残差适配器（细），从而将全局跨被试对应关系与被试特定的残差校正分离开来，用于细粒度的空间和语义校准。为了进一步保持全局表征稳定性，我们设计了一种拓扑锚定的双流流形约束，其中一组少量共享刺激作为拓扑锚点，具有体素级别的成对监督，而语义流则通过冻结的视觉-语言解码器对未配对的大脑数据强制一致性。综合起来，MindAdapter高效地注入被试特定的校正，同时保持预训练期间学到的全局表征几何结构。在自然场景数据集（NSD）上的实验表明，MindAdapter仅使用少量共享刺激就显著提高了跨被试视觉重建和检索的准确率，为个性化大脑到视觉解码提供了一种实用且数据高效的解决方案。

## Abstract
Cross-subject brain-to-visual decoding remains a core challenge in brain-computer interfaces due to severe inter-individual variability that induces systematic subject-specific functional misalignment. To address this issue, we propose MindAdapter, a parameter-efficient few-shot calibration framework for pretrained brain-to-visual decoding models. MindAdapter adopts a decoupled linear-residual cascade alignment paradigm by freezing a pretrained explicit brain functional alignment backbone (coarse) and introducing a lightweight nonlinear residual adapter (fine), thereby disentangling global cross-subject correspondence from subject-specific residual corrections for fine-grained spatial and semantic calibration. To further preserve global representational stability, we design a topology-anchored dual-stream manifold constraint, where a small set of shared stimuli serves as topological pins with voxel-level paired supervision, while a semantic stream enforces consistency through a frozen vision-language decoder on unpaired brain data. Together, MindAdapter efficiently injects subject-specific corrections while maintaining the global representational geometry learned during pretraining. Experiments on the Natural Scenes Dataset (NSD) demonstrate that MindAdapter substantially improves cross-subject visual reconstruction and retrieval accuracy using only a few shared stimuli, offering a practical and data-efficient solution for personalized brain-to-visual decoding.

### 2. 论文提出的方法论
*   **核心思想**：采用**解耦的线性-残差级联（Decoupled Linear–Residual Cascade）** 对齐策略，将预训练的粗粒度全局对齐（线性脑转移矩阵 BTM）冻结，仅学习轻量的**非线性残差适配器**来修正被-试特异性错位。
*   **关键技术细节**：
    *   **残差适配器** $A_\theta$：在冻结的预训练跨被试映射 $F_0$ 之后引入一个轻量 MLP，校准后的映射为 $F_\theta(\mathbf{x}_s) = F_0(\mathbf{x}_s) + A_\theta(F_0(\mathbf{x}_s))$。这样只需学习残差修正量 $A_\theta(F_0(\mathbf{x}_s)) \approx \mathbf{r}(\mathbf{x}_s)$，且该修正直接作用于下游视觉解码器 $G$ 的敏感方向（利用雅可比矩阵 $J_G$ 放大的误差方向）。
    *   **拓扑锚定的双流损失**：
        1.  **配对锚点流**：利用少量共享刺激的成对体素数据 $\{(\mathbf{x}_s^{(i)}, \mathbf{x}_t^{(i)})\}$，施加体素级 MSE 损失和 InfoNCE 式对比损失：
            $$ \mathcal{L}_{\text{anchor}} = \sum_{i=1}^m \left(\alpha \|F_\theta(\mathbf{x}_s^{(i)}) - \mathbf{x}_t^{(i)}\|^2 + \ell_{\text{NCE}}(F_\theta(\mathbf{x}_s^{(i)}), \mathbf{x}_t^{(i)})\right) $$
        2.  **未配对语义流**：利用大量未配对源被试数据，通过冻结的视觉解码器（CLIP）强制预测嵌入与原始图像嵌入的语义一致性：
            $$ \mathcal{L}_{\text{sec}} = \sum_{j=1}^N \ell_{\text{NCE}}\left(G(F_\theta(\mathbf{x}_s^{(j)})), \mathbf{c}_s^{(j)}\right) $$
        3.  **联合优化**：$\mathcal{L} = \lambda \mathcal{L}_{\text{anchor}} + \mathcal{L}_{\text{sec}}$。锚点流提供稀疏的几何约束，语义流防止全局语义结构坍塌。
*   **算法流程**（对应原 Algorithm 1）：
    1. 输入：预训练映射 $F_0$、冻结视觉解码器 $G$、少量成对数据 $\mathcal{P}$、大量未配对源数据 $\mathcal{U}$。
    2. 初始化残差适配器 $A_\theta$ 并定义 $F_\theta(\mathbf{x}_s) = F_0(\mathbf{x}_s) + A_\theta(F_0(\mathbf{x}_s))$。
    3. 每轮迭代交替采样小批量，分别计算锚点流损失 $\mathcal{L}_{\text{anchor}}$ 和语义流损失 $\mathcal{L}_{\text{sec}}$。
    4. 联合损失 $\mathcal{L} = \lambda \mathcal{L}_{\text{anchor}} + \mathcal{L}_{\text{sec}}$，仅更新 $A_\theta$ 参数。
    5. 输出校准后的映射 $F_\theta$。

### 6. 论文的主要结论与发现
*   MindAdapter 仅需**极少（如 32‑64 张）共享刺激**即可有效校准预训练的跨被试脑解码模型，显著提升低层像素相似度与高层语义准确性。
*   **粗‑细解耦范式是核心**：冻结的线性 BTM 保留全局对应，非线性残差适配器精准修正剩余的被试特异性偏差，避免灾难性遗忘。
*   双流损失中，锚点流提供确定性几何约束，语义流防止过拟合和语义漂移，二者互补，强于单流训练。
*   MindAdapter 具有极高的**参数和计算效率**，可训练参数不到 MindEye2 的 1/25，训练仅需数分钟，适合现实部署。
*   残差校准带来的嵌入分布更紧凑、语义聚类更清晰（t‑SNE 验证），且不同被试间保留了高度一致的大尺度功能拓扑。

### 7. 优点
*   **创新性强**：将跨被试对齐从“一次全局映射”革新为“全局主干 + 被试特异性残差”范式，契合个体化脑科学需求。
*   **数据效率极高**：只需几十个共享刺激即可稳定校准，远少于常规训练需求，极具实用价值。
*   **即插即用**：不改变预训练模型权重，适配器轻量，可快速嵌入已有跨被试解码管线。
*   **几何约束巧妙**：双流流形约束将稀疏锚点的体素级锁定与大量未配对数据的语义正则无缝结合，保证可靠性。
*   **实验扎实**：多被试、多指标、多消融、可视化，全面验证了方法的有效性和鲁棒性。

### 8. 不足与局限
*   **复杂场景仍存困难**：在精细物体几何、复杂空间布局和多物体组合场景下，重建仍可能出现结构扭曲或细节错配（文中已指出）。
*   **最少锚点需求**：虽然高效，但安全校准仍需要至少 16 个共享刺激，极端低样本（<16）时性能可能不佳。
*   **数据集单一**：仅在 NSD 数据集（自然场景图像）上验证，未在更多模态（如视频、声音）或更多样化人群（如患者）上测试，泛化性待考证。
*   **下游解码器依赖**：语义流依赖冻结的 CLIP 解码器，若更换视觉骨干，可能需重新设计或调参。
*   **线性骨干的假设**：冻住的 BTM 仍基于线性功能对齐假设，虽然残差适配器修正了部分非线性，但源头上的线性受限可能仍是隐形的天花板。
*   **伦理未深入探讨**：仅说明使用公开去标识数据，未具体讨论跨被试大脑数据可能涉及的隐私和滥用风险（如识别个体）。
