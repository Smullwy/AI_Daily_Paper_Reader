## 摘要
连续吸引子神经网络（CANNs）是大脑编码连续变量（如空间位置、头方向和运动方向）的标准计算框架，并解释了海马位置细胞、内嗅皮层网格细胞和头方向细胞的活动。然而，CANN研究目前较为分散：多数结果依赖于实验室自有的实现，通用模拟器缺乏CANN特有的抽象，并且从脉冲序列到实际记录中的吸引子几何结构之间缺少标准化工具箱。本文提出了一个全面的开源工具箱，统一了完整的CANN研究工作流。它由三个紧密集成的组件构成：1) canns，一个基于 BrainPy/JAX 的 Python 库，提供标准化的 1D/2D CANN、脉冲频率适应性变体、网格细胞网络、分层路径整合模型和类脑吸引子架构，同时包含精选数据集、任务生成器、分析器模块以及用于生物可行可塑性的训练器模块；2) canns-lib，一个 Rust 加速后端，为空间导航工作负载带来数百倍加速，并对基于 Ripser 的持续同调有适度提升；3) ASA（Attractor Structure Analyzer），一个 PySide6 流程，应用持续同调和上同调于实验神经记录，以检测真实数据中的环状和环面吸引子特征。该工具箱附带了细节完整的可复现流水线，能够重现近期的 CANN 成果，包括 SFA 驱动的预期追踪、头方向/位置/网格系统中的 theta 扫描以及分层路径整合。

## Abstract
Continuous attractor neural networks (CANNs) are the canonical computational framework for how the brain encodes continuous variables such as spatial position, head direction, and movement direction, and explain the activity of hippocampal place cells, entorhinal grid cells, and head-direction cells. CANN research, however, is fragmented: most results rest on lab-specific implementations, general-purpose simulators lack CANN-specific abstractions, and the path from spike trains to attractor geometry in real recordings lacks a standardized toolkit. Here, we present a comprehensive open-source toolkit that unifies the full CANN research workflow. It combines three tightly integrated components: 1) canns, a Python library on BrainPy/JAX that provides standardized 1D/2D CANNs, spike-frequency-adaptation variants, grid cell networks, hierarchical path-integration models, and brain-inspired attractor architectures, together with curated datasets, task generators, an analyzer module and trainer modules for biologically plausible plasticity; 2) canns-lib, a Rust acceleration backend delivering hundreds-of-times speedups for spatial-navigation workloads and modest gains for Ripser-based persistent homology; 3) ASA (Attractor Structure Analyzer), a PySide6 pipeline applying persistent homology and cohomology to experimental neural recordings to detect ring-like and toroidal attractor signatures in real data. The toolkit ships with full-detail reproducible pipelines that recover recent CANN results including SFA-driven anticipative tracking, theta sweeps in head-direction/place/grid systems, and hierarchical path integration.

## 2. 方法论
该工具箱由三个协同设计的组件构成。

### 2.1 canns（Python建模与分析层）
- **五层架构**：应用层、功能层（任务/训练器/分析器/工具）、核心模型层、基础层（BrainPy/JAX + Rust FFI）、硬件层（CPU/GPU/TPU）。
- **模型抽象**：所有 CANN 变体（1D/2D 环吸引子、带 SFA 的 CANN、网格细胞、层级路径整合、theta 扫描、脑启发记忆网络）继承自 `BasicModel` 或 `BrainInspiredModel`，共享连接构建、状态初始化、更新等接口。核心动力学沿用 Wu–Amari–Wong（WAW）模型：
  
  $$\small W_{ij} = \frac{J_0}{\sqrt{2\pi a}} \exp\bigl(-\frac{d_{ij}^2}{2a^2}\bigr),\quad \tau \dot u_i = -u_i + \sum_j W_{ij} r_j + I_i,\quad r_i = \frac{[u_i]_+^2}{1 + k\sum_j [u_j]_+^2}$$

  SFA 版本增加慢变量 $a_i$：$\tau_a \dot a_i = -a_i + m u_i$，并作为负反馈加入膜方程。
- **任务模块**：提供 `SmoothTracking1D`、`PopulationCoding` 等跟踪任务，以及独立于模型的闭环/开环导航任务。
- **分析器模块**：包含模型指标（如网格分数）、可视化、数据/拓扑分析（ASA 核心）、不动点分析、模型专用分析和高层工作流。分析器与模型解耦，仅需输出数组。
- **训练器模块**：内置 Hebb、Oja、Sanger、BCM、STDP 等生物学可行塑性规则，通过 `weight_attr` 合约与模型协作。

### 2.2 canns-lib（Rust加速后端）
- **动机**：Python 瓶颈操作（持续同调、长时程空间导航）由 Rust + PyO3 重写，提供透明加速。
- **Ripser 加速**：重写 Vietoris–Rips 持续同调计算，通过逐行边生成、稀疏列二分搜索、结构体数组和 Rayon 多线程实现平均 1.13×、最高 1.82× 加速（对比 Cython/C++ 的 ripser.py）。
- **空间导航加速**：Rust 移植的 RatInABox 环境/代理 API 带来约 700 倍加速（10⁶ 步耗时 0.27 秒 vs 纯 Python 192.8 秒）。

### 2.3 ASA（吸引子结构分析器）
- **数据流**：输入 `.npz`（含 spike 等），经高斯平滑、标准化、PCA 降维后构建时间索引或空间索引的点云 $X_t$ 或 $X_x$。
- **持续同调**：Vietoris–Rips 滤序，输出条码和持续性图；理想环吸引子特征 $(β_0, β_1, β_2)=(1,1,0)$，环面特征 $(1,2,1)$。
- **零模型**：时间分析用循环平移洗牌，空间分析用空间排列洗牌，建立零分布并绘制灰色包络。
- **持续上同调与圆形坐标**：用最小二乘提升余环至实值相位函数 $\theta:X\to\mathbb{S}^1$，可选解码 $m=1$ 或 $m=2$ 个圆形坐标。
- **解释模块**：CohoMap（将解码相位映射回行为空间）、CohoSpace（神经元活动在相位流形上的布局）、PathCompare（行为轨迹与解码相位路径比较）。
- **单细胞拓扑指标**：GridScore（空间自相关旋转对称性）、CohoScore（解码相位的循环方差），以及自动网格阈值搜索工作流。
- **接口**：PySide6 图形界面和命令行均可用，输出带缓存与溯源信息。
