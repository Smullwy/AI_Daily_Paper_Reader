## 摘要
有效的脑疾病诊断需要脑连接模式与高层语义知识的协同。然而，现有方法大多将大语言模型的语义作为辅助特征或监督信号，限制了其在决策中的直接作用，并制约了分类的稳定性和鲁棒性。为此，我们提出了一种语义对齐的脑网络框架，主动将大语言模型导出的语义融入预测过程。具体而言，首先通过全局自注意力结合脑区级语义，丰富节点表示并提供全脑上下文。然后构建多尺度超图，显式建模功能子网络和多脑区交互，克服传统图神经网络的局部性限制，捕获高阶依赖关系。最后，决策级的语义对齐机制将特定于患者的文本嵌入选择性地注入图表示，使语义能够直接引导预测而不扰动底层网络结构。在公开脑网络数据集ABIDE和ADHD-200上的实验表明，该方法在性能、稳定性和可解释性上均达到最优，尤其是在小样本场景下。

## Abstract
Effective brain disease diagnosis requires the synergy of brain connectivity patterns and high-level semantic knowledge. Existing methods, however, largely treat semantics from large language models (LLMs) as auxiliary features or supervision, limiting their direct role in decision-making and constraining classification stability and robustness. To overcome this, we propose a semantic-aligned brain network framework that actively integrates LLM-derived semantics into the prediction process. Specifically, ROI-level semantics are first incorporated via global self-attention to enrich node representations and provide whole-brain context. Multi-scale hypergraphs are then constructed to explicitly model functional subnetworks and multi-ROI interactions, addressing the locality limitations of traditional GNNs and capturing high-order dependencies. Finally, a decision-level semantic alignment mechanism selectively injects patient-specific textual embeddings into graph representations, enabling semantics to directly guide predictions without perturbing the underlying network structure. Experiments on public brain network datasets ABIDE and ADHD-200 demonstrate state-of-the-art performance, enhanced stability, and improved interpretability, particularly in small-sample settings.

## 2. 论文提出的方法论
### 核心思想
提出 **SABER** 框架，分三个阶段逐步将 LLM 语义注入脑网络建模：
- **模块一（节点级）**：用 LLM 生成每个脑区的功能描述，经全局自注意力融合到初始功能连接特征中，形成语义增强的节点表示。
- **模块二（图级）**：基于增强节点特征构建**多尺度超图**，捕获跨脑区的高阶交互；再通过图池化和自适应门控将多尺度特征融合为统一的全脑图表示。
- **模块三（决策级）**：设计一个可学习的 **Graph-CLS** 令牌，与图表示相加后通过交叉注意力从患者文本嵌入中提取个性化语义，再经门控残差注入到图表示中，最后使用交叉熵损失和语义对比损失联合优化，使语义直接引导预测。

### 关键技术细节（文字说明）
- **ROI 语义注入**：使用 LLM 生成 ROI 描述，经冻结文本编码器得到嵌入 $\mathbf{E}_{\text{ROI}} \in \mathbb{R}^{N \times d_{\text{LLM}}}$，线性投影后与原功能连接矩阵相加，送入脑网络 Transformer（BNT）全局自注意力，输出语义浸染的节点特征 $\mathbf{X}'$。
- **多尺度超图构建**：对每个尺度 $k$，基于 $\mathbf{X}'$ 的相似性构建超图 $\mathcal{H}^{(k)}$，超边连接功能相似的 ROI 群组。用超图神经网络（HGNN）进行两层特征传播：  
  $$\mathbf{X}^{(k,l+1)} = \sigma\left( \mathbf{D}_v^{-1/2} \mathbf{H}^{(k)} \mathbf{D}_e^{-1} (\mathbf{H}^{(k)})^{\!\top} \mathbf{D}_v^{-1/2} \mathbf{X}^{(k,l)} \mathbf{W}^{(k,l)} \right)$$  
  随后通过**共享参数**的多头自注意力（MHSA）统一聚合各尺度信息，得到多尺度节点表示 $\mathbf{Z}^{(k)}$。
- **图级抽象与自适应融合**：每个尺度内全局平均池化得到 $\mathbf{g}^{(k)}$，拼接后通过门控网络输出 softmax 权重 $\boldsymbol{\alpha}$，加权融合得到图表示 $\mathbf{g} = \sum_{k} \alpha_k \mathbf{g}^{(k)}$。
- **决策级语义对齐**：引入独立的 Graph-CLS 令牌 $\mathbf{q}_{\text{CLS}}$，与 $\mathbf{g}$ 相加得到查询 $\mathbf{q}$，对患者文本嵌入 $\mathbf{E}_{\text{Patient}}$ 进行交叉注意力，产生语义融合向量 $\mathbf{h}_{\text{fused}}$。再经门控残差注入：  
  $$\mathbf{g}' = \mathbf{g} + \sigma(W_g \mathbf{h}_{\text{fused}}) \odot \mathbf{h}_{\text{fused}}$$
- **双监督训练**：交叉熵损失 $L_{\text{CE}}$ 用于分类；对比损失 $L_{\text{CL}}$ 鼓励 $\mathbf{g}'$ 接近对应疾病的 LLM 文本嵌入，总损失 $L = L_{\text{CE}} + \lambda L_{\text{CL}}$。

## 3. 实验设计
- **数据集**：  
  - **ABIDE I**：871 名受试者（403 ASD，468 正常对照），来自 16 个站点。  
  - **ADHD-200**：947 名受试者（362 ADHD，585 正常对照），来自 8 个中心。  
  均用 DPARSF 预处理，按 8:1:1 分层划分训练/验证/测试集，并补充十折交叉验证。
- **评估指标**：准确率、AUC、召回率、特异度、F1 分数。
- **对比方法**：包括 BrainNetCNN、BrainGNN、BNT、Com-BrainTF、HGNN、BrainNPT、BrainGSL、MADEforASD 和 BrainPrompt 等 9 个基线。
- **变体设置**：还比较了不含 LLM 语义的 **SABER lite** 版本，以量化语义模块的贡献。

## 4. 资源与算力
- 使用单张 **NVIDIA RTX 3090 GPU（24 GB 显存）** 训练。
- 批大小为 16，训练 100 个 epoch。
- 优化器选用 AdamW，初始学习率 $1 \times 10^{-4}$，权重衰减 $1 \times 10^{-4}$，并采用余弦退火学习率调度。

## 6. 论文的主要结论与发现
- SABER 在 ABIDE 和 ADHD-200 上均取得最高准确率（71.58 % 和 66.21 %），显著优于所有基线，验证了决策级语义对齐的有效性。
- 多尺度超图建模有效捕获了传统 GNN 难以表征的高阶脑区交互，即使不含语义的变体（SABER lite）也已优于多数方法。
- Graph-CLS 令牌与门控残差注入使语义能够**选择性引导**预测，同时保持结构完整性，提升了小样本下的鲁棒性与稳定性。
- 判别性 ROI 分析揭示了梭状回、海马、眶额下回等与 ASD 相关的脑区，符合先验文献，证明模型具有良好的神经生物学可解释性。

## 7. 优点
- **系统性语义注入层次**：从节点、图到决策层逐步深化语义参与，设计新颖且逻辑清晰。
- **多尺度超图与共享注意力**：突破常规图的成对限制，有效建模子网络和高阶协作，同时保持跨尺度表达一致性。
- **决策级对齐与门控融合**：让语义直接作用于最终决策，自适应调控语义贡献，增强鲁棒性。
- **全面的验证**：在两个公开多站点数据集上进行对比、消融和超参数研究，还提供了可解释性证据，整体实验可信度高。
