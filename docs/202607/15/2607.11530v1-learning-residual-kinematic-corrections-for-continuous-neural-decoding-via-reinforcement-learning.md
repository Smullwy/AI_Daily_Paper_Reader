## 摘要
基于非侵入性脑电图（EEG）的脑机接口（BCIs）在解码连续三维（3D）运动想象（MI）时，由于信号变异性和残余解码误差，仍面临挑战。卷积神经网络-长短期记忆（CNN-LSTM）等深度学习架构可以捕获空间和时间动态，用于连续运动学解码；然而，预测轨迹中仍存在系统性残差。我们提出了一种两阶段解码框架，该框架应用强化学习（RL）对CNN-LSTM解码器（CNN-LSTM-RL）的输出进行残差运动学校正。RL智能体在离线状态下训练，无需直接输入EEG，而是对预测的运动学轨迹进行操作，以优化相对于目标轨迹的运动精度。解码性能通过沿x、y和z轴的皮尔逊相关系数（r）和均方根误差（RMSE）进行量化。与单独使用CNN-LSTM相比，CNN-LSTM-RL在2D中将平均相关系数从0.5076提高到0.7181（p = 0.0005），在VR中从0.6420提高到0.7780（p = 0.0059），相对增益分别为41.5%和21.2%。相应地，RMSE在2D中从0.0890降至0.0532（p < 0.0001），在VR中从0.0714降至0.0441（p < 0.0001），相对降低分别为40.2%和38.2%。这些发现表明，这一可扩展框架通过离线残差RL校正运动学误差而无需额外神经数据，从而增强了3D BCI MI解码，推进了神经康复、假肢和虚拟交互。

## Abstract
Decoding continuous three-dimensional (3D) motor imagery (MI) using non-invasive electroencephalography (EEG)-based brain--computer interfaces (BCIs) remains challenging due to signal variability and residual decoding errors. Deep learning architectures such as convolutional neural network--long short-term memory (CNN--LSTM) models can capture spatial and temporal dynamics for continuous kinematic decoding; however, systematic residual errors persist in predicted trajectories. We propose a two-stage decoding framework that applies reinforcement learning (RL) to perform residual kinematic correction on the outputs of a CNN--LSTM decoder (CNN--LSTM--RL). The RL agent is trained offline without direct EEG input and instead operates on predicted kinematic trajectories to optimize movement accuracy relative to target trajectories. Decoding performance was quantified using Pearson correlation coefficients ($r$) and Root Mean Square Errors (RMSE) along the $x, y$, and $z$ axes. Compared to CNN--LSTM applied alone, CNN--LSTM--RL improved the mean correlation from $0.5076$ to $0.7181$ ($p = 0.0005$) in 2D and from $0.6420$ to $0.7780$ ($p = 0.0059$) in VR, with relative gains of $41.5\%$ and $21.2\%$, respectively. Correspondingly, RMSE was reduced from $0.0890$ to $0.0532$ (2D, $p < 0.0001$) and from $0.0714$ to $0.0441$ (VR, $p < 0.0001$), representing relative reductions of $40.2\%$ and $38.2\%$. These findings demonstrate that this scalable framework enhances 3D BCI MI decoding by correcting kinematic errors via offline residual RL without extra neural data, advancing neurorehabilitation, prosthetics, and virtual interaction.

## 2. 论文提出的方法论
*   **核心思想**：采用一个两阶段框架（CNN-LSTM-RL）。
    1.  **第一阶段**：使用一个预训练的CNN-LSTM解码器，从EEG中解码出原始的连续三维运动速度 $v^{\text{BCI}}_t$。该解码器在后续过程中被冻结。
    2.  **第二阶段**：离线训练一个强化学习（RL）智能体，其任务是根据解码器输出的轨迹生成一个残差速度 $v^{\text{res}}_t$，以校正原始解码结果。校正后的最终速度为 $v_t = v^{\text{BCI}}_t + v^{\text{res}}_t$。
*   **技术细节**：
    *   RL问题的状态 $s_t$ 是部分可观测的，智能体的观测 $o_t$ 仅包含 $[v^{\text{BCI}}_t, v_{t-1}, t]$，无需访问原始EEG信号或目标速度。
    *   即时奖励函数被设计为最小化校正后速度与目标速度之间的欧几里得距离的负值：$r_t = -d(v_t, v^*_t)$。
    *   采用的优势演员-评论家（SAC）算法，目标是最大化累积奖励与策略熵的组合，以平衡探索与利用：$J(\pi) = \sum_{t=0}^{T} \mathbb{E}_{(s_t,a_t)\sim\pi} [r(s_t, a_t) + \alpha \mathcal{H}(\pi(\cdot|s_t))]$。
    *   为解决不同空间维度可能需要的不同校正幅度，对SAC算法的动作输出应用了维度特定的缩放因子，并相应修正了对数概率密度的计算：$\log \pi(a_t|s_t) = \log \mathcal{N}(u_t | \mu(s_t), \sigma^2(s_t)) - \sum_{i=1}^{D} \log(1 - \tanh^2(u_{i,t})) - \sum_{i=1}^{D} \log(\text{scale}_i)$。

## 3. 实验设计
*   **数据集**：自采集数据集，包含10名右利手受试者在2D屏幕和沉浸式虚拟现实（VR）两种反馈条件下，执行/想象上肢伸向4个目标任务的10个session的数据（共25,600次试验）。实验范式定义清晰，包含休息、指示、目标、重置四个阶段。
*   **基准方法（Benchmark）**：以未加RL校正的CNN-LSTM解码器在不同训练/测试策略下的表现为基准。
    *   **FDG（固定解码器泛化）**：仅在Session 1上训练解码器，在Session 1-5上进行测试，模拟真实在线BCI场景。
    *   **SAT（顺序自适应训练）**：在每个前一session上训练，在下一session上测试。
    *   **WSR（同一session内重建）**：在同一session内训练和测试，提供性能的理论上界。
*   **对比方法**：主要对比所提方法**FRL（固定强化学习）**与上述三种基线（FDG, SAT, WSR）的性能差异。FRL仅在Session 1的数据上训练RL代理，并在后续所有session中保持代理不变。

*   **任务定义清晰**：将残差校正建模为一个部分可观察的马尔可夫决策过程（POMDP），并利用SAC算法优化，理论框架明确。

## 8. 不足与局限
*   **任务范式受限**：目前仅在**四目标离散伸够任务**上进行验证，运动模式相对简单，对于更复杂的、非提示的自发连续运动意图的解码能力尚不明确。
*   **离线与在线的差距**：尽管FRL是离线训练的，评估也是离线分析，但其在真实在线BCI反馈循环下的性能、延迟及与用户的适应性尚未得到验证。
*   **对时间信息的依赖**：论文提到RL代理的性能高度依赖**时间变量 $t$ 作为观测**，这使得该方法难以直接应用于对启动时间未知的异步BCI场景。
*   **对基解码器的依赖**：作为一种残差方法，其性能上限仍然受制于底层CNN-LSTM解码器的初始质量。解码器性能太差，RL将无法有效纠正。
