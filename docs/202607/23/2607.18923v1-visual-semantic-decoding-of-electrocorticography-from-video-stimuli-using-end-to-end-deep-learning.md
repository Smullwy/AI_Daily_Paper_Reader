## 摘要
基于皮层脑电图（ECoG）的视觉语义解码能够从复杂、嘈杂的大脑活动中推断出视觉感知的语义解释。本研究探讨了使用端到端深度学习框架和皮层脑电图（ECoG）进行视觉语义解码的可行性。具体而言，解码任务是利用时间序列神经输入，从视频刺激中预测视觉类别。分析使用了一个先前收集的来自耐药性癫痫参与者（n=17）的ECoG数据集。在每类视觉类别训练样本少于50个的情况下，本研究评估了多种深度学习方法、人工神经网络架构和频段滤波输入。对表现最佳的方法进行分析，以揭示其在频谱、时间和皮层维度上所依赖的判别信息。所选解码系统使用了mixup数据增强、基于Transformer的编码器，以及经过900毫秒刺激后时间窗的高伽马频段（80-150 Hz）输入。进一步分析显示，早期视觉皮层（V2-V4）、腹侧流视觉皮层、MT+复合体及其邻近视觉区域，以及外侧颞叶皮层对解码性能贡献显著。本研究表明，端到端深度学习框架可以在没有手工特征的情况下，从动态视觉刺激中获得有前景的解码性能，同时模型行为通过频谱、时间和皮层维度保持可解释性，这与既定的神经科学知识广泛一致。

## Abstract
ECoG-based visual semantic decoding enables inference of semantic interpretation of visual perception from complex, noisy brain activity. This study examines the feasibility of visual semantic decoding using an end-to-end deep learning framework using electrocorticography (ECoG). Specifically, the decoding task is to predict visual categories from video stimuli using time-series neural inputs. A previously collected ECoG dataset from participants ($n=17$) with drug-resistant epilepsy is used for analysis. With fewer than 50 training samples per visual category, this study evaluates multiple deep learning approaches, artificial neural network architectures, and frequency-band filtered inputs. The best-performing approach is analyzed to shed light on the discriminative information it relies on across spectral, temporal, and cortical dimensions. The selected decoding system uses mixup augmentation, a Transformer-based encoder, and high-gamma (80-150 Hz) inputs with a 900 ms post-stimulus window. Further analysis shows that early visual cortex (V2-V4), ventral stream visual cortex, MT+ complex with neighbouring visual areas, and lateral temporal cortex contributed substantially to decoding performance. This study demonstrates that an end-to-end deep learning framework can yield promising decoding performance from dynamic visual stimuli without handcrafted features, while the model behavior remains interpretable through spectral, temporal, and cortical dimensions, which are broadly consistent with established neuroscience knowledge.

## 2. 论文提出的方法论
### 2.1 核心思想
本研究的核心思想是建立一个端到端的解码框架，通过对比多种深度学习策略、编码器架构和信号频段输入，寻找一套在极少样本下既实用又可靠的方案，并深入分析最佳模型的行为，以验证其神经生理学上的合理性。

### 2.2 关键技术细节
- **低资源学习策略**：评估了三种解决标签稀缺问题的方法。
  - **原型网络（ProtoNet）**：通过在每个训练片段（episode）中计算类别的平均嵌入来分类，适用于小样本（few-shot）场景。
  - **数据增强（Mixup）**：在输入层或首个隐层对两个样本及其标签进行随机线性插值，公式为$\tilde{x} = \lambda x_i + (1-\lambda) x_j$，并用加权交叉熵损失$L_{\text{mixup}} = \lambda L_{\text{CE}}(\hat{y}, y_i) + (1-\lambda) L_{\text{CE}}(\hat{y}, y_j)$进行优化，以创建平滑的决策边界。
  - **自监督对比学习（SimCLR）**：利用大量无标签数据预训练编码器，通过对比损失拉近同一数据不同增强视图的距离，再在下游任务中用少量有标签数据微调。
- **模型架构组件**：
  - **编码器**：测试了六种轻量级架构，包括 ResNet、LSNet、TCN、EEGNet、BiLSTM 和 Transformer。
  - **池化与分类**：编码后的特征通过全局平均池化或时序注意力池化聚合成定长向量，再经由一个可选的投影头（两层 MLP + ReLU）送入线性分类器。
- **多频段融合模型**：为解决 Transformer 处理宽带信号时性能不佳的问题，提出了一种“分而治之”的融合策略。将宽带信号分解为 alpha、beta、low-gamma、high-gamma 等窄带，分别通过各自预训练且权重冻结的编码器提取特征 $z_s$，再通过学习到的标量权重 $w_s$ 进行融合，得到最终表示 $z_{\text{fused}} = \sum_{s} w_s z_s$，用于分类。

### 2.3 模型可解释性分析
- **注意力图可视化**：检查 Transformer 最后一层自注意力权重图，分析其对不同频段信号时间结构的敏感性。
- **信号扰动实验**：在推理阶段对输入信号进行“恒定RMS”和“相位置乱”扰动，通过观察解码准确率的变化，量化频谱功率与相位信息对模型的贡献度。
- **皮层区域重要性**：使用一种基于置换的重要性度量方法。对于每个皮层区域，用阴性样本的对应通道信号替换其真实信号，通过计算平衡准确率的下降量（$\Delta\text{BA}$）来量化该区域对解码的重要性。
- **互信息分析**：计算高伽马频段频谱功率与视觉类别标签之间的归一化互信息（$\Delta\text{NMI}$），并将其与解码性能做相关性分析。

## 6. 论文的主要结论与发现
- **低资源学习**：Mixup 数据增强在所有深度学习方法中表现出最佳的性价比，它优于标准监督学习和原型网络，性能与计算成本高的 SimCLR 方法相当，更适合实用型 BCI。
- **最优模型与输入**：Transformer 编码器结合高伽马频段（80-150 Hz）信号输入，是实现视觉语义解码的最有效组合。
- **频谱与时间特征**：模型主要依赖于高伽马频段的频谱功率进行解码，而非相位信息。900 毫秒的刺激后时间窗提供了最佳的群体级平均解码性能。
- **皮层贡献**：解码性能高度依赖于视觉通路的层级化处理区域。早期视觉皮层（V2-V4）、腹侧流视觉皮层、MT+ 复合体和外侧颞叶皮层是贡献最大的脑区，这与既有的层级视觉加工理论高度一致。
- **Transformer 的局限与解决方案**：Transformer 由于自注意力机制难以解耦宽频信号中混合的频谱信息，导致其在直接处理宽带信号时性能不佳。通过“先分解、后融合”的多频段融合策略，显著提升了其宽带解码性能，但性能未能超越单独使用高伽马频段，表明高伽马频段包含了绝大部分必要信息。
- **模型可靠性**：模型的行为模式在频谱、时间和皮层空间维度上均可解释，并与神经科学知识一致，增加了其在临床应用中产生可靠决策的潜力。

- **多维度可解释性分析**：系统性地从频谱（注意力图、扰动实验）、时间（窗口大小分析）和空间（皮层区域重要性）三个维度解释模型行为，超越了“黑箱”式的性能报告，为模型在临床 BCI 中的可靠性提供了有力支撑。

## 8. 不足与局限
- **人群普适性**：所有数据均来自耐药性癫痫患者，其大脑功能连接和活动模式可能与健康人群存在差异，结论的普适性有限。
- **刺激特异性**：标签（人脸、文本、风景）与视频中的低级视觉特征（如对比度、空间频率、运动）可能存在高度相关性，无法完全确定解码的是高级语义还是低级视觉特征。
- **电极覆盖的个体差异**：受限于临床需求，电极位置和数量在受试者间差异巨大，这虽然反映了真实世界的挑战，但也导致部分脑区的分析结果置信度不高。对于无或仅有少量电极覆盖的区域，其贡献可能被低估。
- **分析基线非最优**：主要的模型架构和频段对比实验基于 500ms 时间窗完成，而后续分析证明 900ms 才是最优窗，这使得前期对比实验的结论可能不是最优配置下的结果。
- **解释性研究的局限性**：注意力图、扰动实验等分析结果均为模型导向的解释，它们揭示了模型所利用的信息，但不等同于直接证明大脑的神经编码机制。

## 9. 总结
本文通过系统而严谨的实验，展示了一个端到端深度学习框架，即使在临床 ECoG 数据样本量极少的挑战下，也能有效解码由动态视频刺激产生的视觉语义类别。该研究不仅识别出高伽马频段活动和 900 毫秒时间窗是关键的解码信息载体，更重要的是，通过对模型行为的频谱-时间-空间多维度分析，成功将模型决策与既有的视觉层级加工神经科学知识对齐，为构建可靠、可解释的临床脑机接口系统提供了有价值的范式和技术路径。
