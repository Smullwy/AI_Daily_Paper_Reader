## 摘要
在多被试时空数据中建模共享与个体特异结构仍然具有挑战性，特别是在神经影像学中，空间和时间模式在被试间都展现出丰富的变异性。现有的矩阵和张量分解提供了可解释的因式分解，但依赖于可能限制其捕捉复杂变异性灵活性的固定多线性结构或耦合方案。本文中，我们引入了一个时空变分张量分解（ST-VTD）框架，该框架结合了张量因子分解生成模型与结构化先验，以联合表示空间图谱和时间动态。空间因子受到受LL1分解启发的低秩结构正则化，而时间因子则使用基于学习的长短期记忆（LSTM）先验进行建模，从而实现灵活的自适应动态。后验推断通过展开优化算法的迭代，使用摊销变分公式执行，从而形成一个可解释且参数高效的架构。所提出的推断框架采用基于组独立成分分析的预热策略，我们发现这种策略能够改善优化性能。在真实的合成功能磁共振成像（fMRI）数据集上的实验表明，与代表性的经典和概率分解基准相比，所提出的方法显著改善了潜在因子的恢复。

## Abstract
Modeling shared and subject-specific structure in multisubject spatiotemporal data remains challenging, particularly in neuroimaging, where both spatial and temporal patterns exhibit rich variability across subjects. Existing matrix and tensor decompositions provide interpretable factorizations, but rely on fixed multilinear structures or coupling schemes that may limit their flexibility in capturing complex variability. In this work, we introduce a spatiotemporal variational tensor decomposition (ST-VTD) framework that combines a tensor factorization generative model with structured priors to jointly represent spatial maps and temporal dynamics. Spatial factors are regularized to promote a low-rank structure inspired by the LL1 decomposition, while temporal factors are modeled using a learned Long short-term memory (LSTM)-based prior, enabling flexible and adaptive dynamics. Posterior inference is performed using an amortized variational formulation by unrolling iterations of an optimization algorithm, leading to an interpretable and parameter-efficient architecture. The proposed inference framework employs a warm-start strategy based on group independent component analysis, which we found to improve optimization performance. Experiments on a realistic synthetic functional MRI (fMRI) dataset demonstrate that the proposed approach significantly improves latent factor recovery compared with representative classical and probabilistic decomposition benchmarks.

## 1. 论文的核心问题与整体含义
*   **研究动机**：多被试时空数据（尤其是fMRI）分析的核心挑战，在于如何有效建模所有被试共享的公共结构，同时保留每个被试独有的空间与时间变异。现有多线性分解方法（如GICA、CPD）结构约束过于刚性，难以灵活捕捉这种复杂变异。
*   **核心问题**：如何在统一的概率生成框架下，既利用结构化的低秩先验保持空间图谱的可解释性，又能通过灵活的动力学先验捕捉复杂的时间依赖关系，从而更精准地从多被试数据中恢复潜在因子。

## 2. 论文提出的方法论
论文的核心是时空变分张量分解框架ST-VTD，它由三部分关键设计构成：

*   **生成模型**：将每个被试 $n$ 的观测数据张量 $\mathcal{X}^{(n)} \in \mathbb{R}^{T \times V_x \times V_y}$ 建模为 $K$ 个空间图谱 $\mathbf{Z}_k^{(n)}$ 和时间过程 $\mathbf{c}_k^{(n)}$ 的外积和，即 $\mathcal{X}^{(n)} = \sum_{k=1}^{K} \mathbf{Z}_k^{(n)} \circ \mathbf{c}_k^{(n)} + \mathcal{E}^{(n)}$。
*   **结构化先验**：
    *   **空间低秩先验 $p(\mathbf{Z}_k)$**：受LL1分解启发，强制每个空间图谱为两个低秩因子 $\mathbf{U}_k$ 和 $\mathbf{V}_k$ 的乘积形式，即 $p(\mathbf{Z}_k) = \mathcal{N}(\mathbf{U}_k \mathbf{V}_k^\top, \lambda_k^2 \mathbf{1})$。这减少了空间参数，同时保留了局部平滑结构。
    *   **时间LSTM先验 $p(\mathbf{c}_k)$**：使用一个参数为 $\theta_k$ 的长短期记忆网络（LSTM）来生成时间过程的均值，即 $p(\mathbf{c}_k) = \mathcal{N}(w(t， \theta_k)， \gamma_k)$。这使得时间动态可以是非线性的，并能捕捉长程依赖关系。
*   **推断策略**：采用摊销变分推断，并创新性地通过“算法展开”设计推断网络，使其结构与生成模型先验相匹配。
    *   **近似后验 $q$**：使用均场高斯分布 $q(\mathbf{Z}, \mathbf{C}|\mathcal{X}) = \prod_k q(\mathbf{Z}_k|\mathcal{X}) q(\mathbf{c}_k|\mathcal{X})$。
    *   **核心架构（算法展开）**：为获得后验均值的可解释计算，将LPALM优化算法的 $I$ 次迭代展开成一个神经网络。该网络输入为数据 $\mathbf{X}$（张量矩阵化），通过交替梯度下降和**列向低秩投影** $P_{LR}(\cdot)$ 来更新时空因子。展开网络从**基于GICA的预热初始值** $\mathbf{Z}^{(0)}_{\text{GICA}}$ 开始。
    *   **方差推断**：后验方差由轻量级MLP从优化得到的均值中计算得出。
    *   **训练目标**：通过最大化证据下界 $\mathcal{L}_{\theta，\phi}(\mathcal{X})$ 来联合优化生成模型参数 $\theta$ 和变分后验参数 $\phi$，其中KL项采用线性预热策略。

## 3. 实验设计
*   **数据集**：作者构建了一个**半合成（hybrid synthetic）fMRI数据集**。具体为：
    *   **空间图谱**：从Neuromark fMRI图谱中选取 $K=10$ 个真实轴向空间图谱作为模板，通过对每个被试施加微小的几何扰动来引入个体变异性。
    *   **时间过程**：为每个被试生成具有振幅、相位偏移和噪声差异的平滑时间序列。
    *   **数据合成**：根据生成模型公式(1)组合时空成分，并加入高斯白噪声，生成 $N=100$ 个被试、$T=150$ 时间点、$V_x=V_y=30$ 像素的张量数据。
*   **基准模型**：选取了四种具有代表性的方法进行对比：
    1.  **GICA**：组独立成分分析，经典的共享空间模型。
    2.  **LL1**：多线性秩-$(L_r, L_r, 1)$ 分解，对每个被试独立拟合。
    3.  **BCPF**：贝叶斯CP分解，概率分解模型。
    4.  **PARAFAC2**：允许时间因子跨被试变化，但空间图谱共享的灵活模型。
