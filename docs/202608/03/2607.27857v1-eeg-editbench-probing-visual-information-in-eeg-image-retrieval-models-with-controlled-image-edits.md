## 摘要
最近的EEG到图像检索模型在从语义多样的候选图像中识别所视图像方面取得了强大性能。然而，这样的成功并未揭示何种视觉信息支持匹配。模型可能很容易在工具、植物和车辆中识别出一只猎豹，但它能否从同一场景中区分出所视的猎豹，如果猎豹被替换为一只狗？受此问题启发，我们引入了EEG-EditBench，这是一个诊断基准，通过受控编辑对象身份、属性、背景和对象存在来检验该问题。EEG-EditBench基于200 THINGS-EEG2测试图像构建，包含2,137幅经过质量控制的编辑图像，并评估了八个代表性的EEG视觉解码模型。我们的结果表明，在标准检索中表现强劲并不总能迁移到基于编辑的评估，细粒度属性变化带来了最大挑战。EEG-EditBench揭示了被总体检索精度所隐藏的模型行为，并为研究EEG-图像模型保留了何种视觉信息提供了受控基础。代码和完整数据集已公开。

## Abstract
Recent EEG-to-image retrieval models have achieved strong performance in identifying viewed images from semantically diverse candidates. Yet such success does not reveal what visual information supports the match. A model may readily identify a cheetah among tools, plants, and vehicles, but can it still distinguish the viewed cheetah from the same scene with the cheetah replaced by a dog? Motivated by this question, we introduce EEG-EditBench, a diagnostic benchmark that examines this question through controlled edits of object identity, attributes, background, and object presence. Built from the 200 THINGS-EEG2 test images, EEG-EditBench contains 2,137 quality-controlled edits and evaluates eight representative EEG visual decoding models. Our results show that strong standard retrieval does not consistently transfer to edit-based evaluation, with fine-grained attribute changes presenting the greatest challenge. EEG-EditBench reveals model behavior hidden by aggregate retrieval accuracy and provides a controlled basis for studying what visual information EEG-image models preserve. The code and complete dataset are publicly available.

## 2. 论文提出的方法论
- **核心思想**：通过对原始图像进行受控的、因子级别的编辑（替换对象、修改属性、更换背景、移除对象），构造一组与源图像语义相近但视觉细节不同的“诊断探针”，转而测试模型能否通过 EEG 信号区分源图像与其编辑变体。
- **编辑分类与构建**：
  - **对象身份编辑（Object Identity）**：将图像中的核心物体替换为语义相近（如猫→狗）或语义较远（如猎豹→沙发）的物体，用于探测类别级信息保留。
  - **属性编辑（Attribute）**：改变物体的材质、纹理、形状、大小、颜色、物理状态等属性，探测细粒度视觉特征的保留情况。
  - **背景编辑（Background）**：替换或去除背景场景，测试模型对场景上下文的依赖。
  - **存在性编辑（Removal）**：移除目标物体，考察模型对物体本身存在的敏感性。
- **构建流程**：基于 THINGS‑EEG2 测试集中的 200 张图像，先为每张图像生成结构化场景描述（Scene Profile），再根据编辑家族生成具体的编辑指令（如“将狗替换为猫”），利用图像编辑模型生成候选图像，最后经过人工或自动质量筛选，形成 2 137 幅高质量编辑样本。
- **评估指标**：引入两种基于编辑的设置：
  - **EP‑Top1（Edit‑Probe Top‑1）**：在包含源图像和若干编辑图像的小型候选集中，模型直接选出源图像的正确率。
  - **2AFC（二选一强制选择）**：每次将源图像与一幅编辑图像配对，要求模型根据 EEG 信号判断哪一幅是所视图像，取平均准确率。
  这两种指标直接衡量模型对编辑因素的敏感性。

## 6. 论文的主要结论与发现
- 标准检索的高性能与编辑条件下的诊断性能之间没有必然联系：部分模型在标准 200‑way 检索中准确率很高，但在编辑探针任务中表现大幅下降。
- **细粒度属性变化是最具挑战性的编辑类型**，模型对材质、纹理、形状等属性的改变最不敏感。
- 对象身份编辑在身份差异较大时模型尚能识别，但语义邻近的对象替换（如猫→狗）仍造成显著混淆。
- 背景和物体存在性移除的影响相对较小，说明模型可能更关注前景物体的抽象类别而非场景上下文。
- EEG 嵌入空间分析表明，编辑后图像在表示上并无一致地向目标概念方向移动，反映出模型未能有效编码物体身份信息的细微差异。

## 7. 优点
- **诊断导向的基准设计**：用受控编辑替代随意选择的负样本，将评估从“能否从杂件中认出”提升到“能否区分精细变体”，显著增强了对模型内部视觉理解力的探测力。
- **编辑分类的系统性**：覆盖身份、属性、背景、存在性四个维度，且属性维度进一步细分为多种子类，解剖粒度细腻。
- **双指标评估**：EP‑Top1 与 2AFC 互补，既考察直接检索能力，又排除候选集大小干扰，评估方式严谨。
- **开源可复现**：提供完整数据集与代码，便于社区基于此开发更敏感的评估方法和模型。

## 8. 不足与局限
- **编辑质量的依赖**：部分自动编辑可能引入不自然的伪影或语义矛盾，尽管进行了质量控制，但仍可能混淆模型的响应。
- **单模态EEG基准**：仅基于 THINGS‑EEG2 这一单一数据集和固定刺激范式，结论向其他 EEG 数据或更复杂视觉刺激（如自然视频）的泛化性未知。
- **模型覆盖**：主要集中在检索与简单回归模型，未包含最新的生成式脑解码模型（如扩散模型直接生成图像），这些模型的编辑敏感性可能不同。
- **缺乏被试层面的信度分析**：未报告不同被试之间编辑效应的稳定性，可能掩盖个体差异对模型行为的影响。
- **“视觉信息保留”的归因局限**：只能揭示模型是否使用了某种视觉信息，但不能确定该信息是在 EEG 特征提取阶段丢失还是在图像嵌入匹配阶段未被利用。

## 9. 总结
EEG‑EditBench 通过因子化、受控的图像编辑，系统地暴露了现有 EEG‑图像检索模型在精细视觉感知上的重大缺口，证明高检索准确率并不等价于对视觉细节的有效编码。该基准不仅为脑解码模型的诊断提供了新工具，也为未来设计更能忠实再现视觉内容的 EEG 解码方法指明了优化方向。
