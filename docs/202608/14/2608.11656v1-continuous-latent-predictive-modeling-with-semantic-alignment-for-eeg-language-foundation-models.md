## 摘要
近期脑电基础模型的进展证明了大规模预训练在实现跨受试者、记录环境和数据集的泛化神经解码方面的潜力。然而，主流预训练范式面临关键挑战：掩码自编码往往优先考虑低级信号重建而忽视任务相关语义，而自回归建模则造成连续神经动态与离散词元空间之间的不匹配。为应对这些挑战，需要新的策略来有效对齐连续脑电表示与自然语言语义，并使其能够与大型语言模型集成。因此，我们提出脑潜在预测模型（BLPM），这是一种脑电-语言基础模型，将异构脑电解码任务重新表述为连续语义嵌入预测问题。BLPM 引入连续脑电潜在预测（CELP）编码器，通过潜在目标预测学习可迁移表示。在这些表示的基础上，多查询语义分解（MQSD）模块提取任务相关信息，并根据语义关系在共享潜在空间中将连续脑电表示与文本语义对齐。跨多个基准的实验展示了在不同任务上一致的泛化性能，确立了连续潜在语义预测作为脑电-语言基础模型的有效范式。

## Abstract
Recent advances in EEG foundation models have demonstrated the potential of large-scale pretraining to enable generalizable neural decoding across subjects, recording environments, and datasets. However, dominant pretraining paradigms face key challenges: masked autoencoding tends to prioritize low-level signal reconstruction over task-relevant semantics, while autoregressive modeling creates a mismatch between continuous neural dynamics and discrete token spaces. To address these challenges, new strategies are needed to effectively align continuous EEG representations with natural-language semantics and enable their integration with large language models. Accordingly, we propose Brain Latent Predictive Model (BLPM), an EEG-language foundation model that reformulates heterogeneous EEG decoding tasks as a continuous semantic embedding prediction problem. BLPM introduces a Continuous EEG Latent Predictive (CELP) encoder that learns transferable representations through latent target prediction. Building on these representations, a Multi-Query Semantic Decomposition (MQSD) module extracts task-relevant information and aligns continuous EEG representations with textual semantics within a shared latent space according to their semantic relationships. Experiments across multiple benchmarks demonstrate consistent generalization performance across diverse tasks, establishing continuous latent semantic prediction as an effective paradigm for EEG-language foundation models.

## 2. 方法论

### 2.1 连续 EEG 潜在预测编码器（CELP）

- **输入与 patch 嵌入**：将 EEG 分成不重叠片段，得到 $C\times P\times L$ 的 token 序列；每个 token 通过双分支嵌入：时间分支用 1D 卷积，频谱分支用 FFT 幅度谱投影，二者加性融合；再用深度可分离卷积注入时空位置信息。
- **联合潜在预测预训练**：采用类似 JEPA 的在线编码器、目标编码器和预测器结构：
  - 结构化多块掩码同时覆盖时间跨度和通道块，鼓励模型利用时间连续性、通道依赖和上下文。
  - 在线编码器 $f_\theta$ 只处理可见 token，得到可见潜在表示 $H_v$。
  - 目标编码器 $f_{\bar{\theta}}$ 处理完整序列，其参数通过 EMA 更新：$\bar{\theta}^{(k)} \leftarrow m_k \bar{\theta}^{(k-1)} + (1-m_k)\theta^{(k)}$，提供稳定的预测目标。
  - 预测器 $g_\phi$ 根据可见上下文和可学习掩码 token 预测被掩蔽位置的潜在表示。
- **损失函数**：在潜在空间计算 Smooth L1 损失，目标经过 LayerNorm：  
  $$L_{\text{CELP}} = \frac{1}{|\mathcal{M}|}\sum_{M_p\in\mathcal{M}}\frac{1}{|M_p|}\sum_{i\in M_p}\rho\left(\hat{h}_i,\mathrm{LN}(h_{t,i})\right)$$
  其中 $\rho$ 为 Smooth L1 损失。预训练完成后仅保留在线编码器。

### 2.2 多查询语义分解（MQSD）

- 冻结 CELP 编码器，将 EEG 嵌入展平为 token 序列 $h$。
- 定义 $M$ 个固定语义查询，对应时间动态、频谱特征、空间关系、形态模式；每个查询通过 LLM 输入嵌入层得到 $Q_m$。
- 每个查询独立与 EEG token 进行交叉注意力，再做掩码平均池化，得到语义摘要 $\tilde{s}_m$，并投影到 LLM 隐藏维度，得到 $s_m$。
- 所有语义摘要构成 $S_q=[s_1;\dots;s_M]$；同时 EEG token 也通过投影 $u=P_u(h)$ 保留细粒度信息。
- 将 $[S_q; u]$ 拼接后送入语义嵌入预测器 $G$，该预测器由预训练 LLM 解码层组成，但使用**双向注意力掩码**而非因果掩码，目标是预测语义嵌入而非生成 token。
- 取出与语义查询对应的隐藏状态，均值池化后经预测头 $P_e$ 映射到文本嵌入空间，得到 $z_e=\mathrm{norm}(P_e(h_{\text{pred}}))$。
- 文本分支：类别标签的自然语言文本 $\ell_y$ 通过预训练文本嵌入模型得到 $z_y=\mathrm{norm}(E_{\text{text}}(\ell_y))$。
- 对齐损失采用双向多正例 InfoNCE：  
  $$L_{\text{align}}=\frac{1}{2}\left(L_{e\to t}+L_{t\to e}\right)$$  
  同一语义文本的样本被视为正例，避免同类样本成为假负例。
