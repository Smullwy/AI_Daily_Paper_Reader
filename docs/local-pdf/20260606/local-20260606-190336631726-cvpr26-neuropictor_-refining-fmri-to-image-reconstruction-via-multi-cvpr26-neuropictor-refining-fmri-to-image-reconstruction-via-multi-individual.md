## 摘要
近期的fMRI到图像方法主要侧重于将fMRI信号与预训练扩散模型的特定条件关联。这些方法虽然能生成高质量图像，但仅捕获了fMRI信号中复杂信息的有限方面，且对图像生成缺乏细节控制。相比之下，本文提出直接用fMRI信号调制扩散模型的生成过程。我们的方法NeuroPictor将fMRI到图像过程分为三步：i) fMRI校准编码，解决多对象预训练共享潜在空间问题，以最小化个体差异并支持后续多对象训练；ii) fMRI到图像的多对象预训练，感知学习以高、低层条件跨不同个体引导扩散模型；iii) fMRI到图像的单对象精化，与步骤ii类似但专注于适应特定个体。NeuroPictor从fMRI信号中提取表征视觉刺激的高层语义特征，并通过低层操控网络逐步微调扩散模型，以提供精确的结构指引。通过使用来自不同个体的大约67,000个fMRI-图像对进行训练，我们的模型具备了优越的fMRI到图像解码能力，尤其在受试者内设定下，在基准数据集上得到了验证。代码和模型见https://jingyanghuo.github.io/ neuropictor/。

### 2. 论文提出的方法论

核心思想是将fMRI-to-image过程分解为三个递进步骤，并设计高低层双支路网络来全面调制扩散模型。

- **三步训练策略**：
    1.  **fMRI校准编码 (Calibrated-Encoding)**：为解决个体差异，在UK Biobank（UKB）大规模数据集上预训练一个掩码自编码器（MAE），将不同个体的一维fMRI信号转换为统一的二维脑表面图，并学习一个共享的、无压缩的通用fMRI潜在空间。
    2.  **多被试预训练 (Multi-subject Pre-training)**：在统一的潜在空间基础上，使用来自多个个体的约67,000个fMRI-图像对，端到端地训练完整的fMRI-to-image模型，学习共享视觉感知模式。
    3.  **单被试精化 (Single-subject Refining)**：针对特定个体的数据，对整个模型进行微调，以适配其独特的脑活动模式。

- **双支路调制网络**：从通用fMRI表征 $S^r$ 中解耦出两类信息，用于引导扩散模型。
    - **高层语义特征学习 (High-Level Guiding Network, HLGN)**：
        - **目标**：替代扩散模型原有的文本条件，为图像生成提供高层语义指导。
        - **设计**：
            - `fMRI-to-Text Encoder`：将fMRI表征映射为估计的CLIP文本特征 $\tilde{F}^{\text{txt}}$，并使用MSE损失 $\mathcal{L}_{\text{sem}}$ 与真实图像标题的CLIP文本特征 $F^{\text{txt}}$ 进行对齐。
            - `Auxiliary Encoder`：生成辅助语义码 $F^{\text{au}}$，以残差方式与 $\tilde{F}^{\text{txt}}$ 相加，形成最终语义表征 $F^{\text{sem}} = \tilde{F}^{\text{txt}} + F^{\text{au}}$，以弥补fMRI-to-text映射可能不准确的缺陷。
    - **低层结构操控网络 (Low-Level Manipulation Network, LLMN)**：
        - **目标**：直接操控扩散模型U-Net的特征图，注入精确的结构和姿态信息。
        - **设计**：
            - `Feature Transformation`：通过一维卷积和MLP，将fMRI表征 $S^r$ 转换为与U-Net特征图维度相同的初始特征图 $F^l_0$。
            - `Manipulator`：该模块是可训练的U-Net编码器的副本，其输入主要包括 $F^l_0$。它输出一系列特征图，通过零卷积层以残差形式注入到冻结的稳定扩散（SD）模型U-Net的对应层中，更新其潜码： $\tilde{F^l} = F_{sd} + \alpha \mathcal{Z}(F^l)$，其中 $\alpha$ 是控制尺度的超参数。

- **统一训练目标**：模型各组件（fMRI编码器、HLGN、LLMN）联合优化，最终损失函数为 $\mathcal{L} = \mathcal{L}_{\text{dif}} + \lambda \mathcal{L}_{\text{sem}}$，其中 $\mathcal{L}_{\text{dif}}$ 是扩散模型的去噪损失。

- 多个体预训练能够有效捕捉不同个体间的共享视觉感知特征，这对解决个体数据稀缺问题至关重要。
- 将fMRI信号解耦为高层语义和低层结构，并分别通过HLGN和LLMN来引导扩散模型，是实现精确、高保真图像重建的关键。这种解耦也实现了图像结构和语义的互换编辑。
- 端到端的直接调制训练方式，避免了分步处理中的信息损失和误差累积，优于先生成模糊中间图像再精化的范式。

### 7. 优点

- **方法上的创新**：首次提出直接利用fMRI信号调制扩散模型生成过程的框架，并成功解耦高低层信息进行多级引导，效果显著。
- **策略上的突破**：提出通过构建统一fMRI表征空间来实现多被试预训练，再为特定个体进行精化的范式，为脑解码领域提供了向“基础模型”发展的新思路，有效缓解了数据瓶颈。
- **实验与分析的严谨性**：实验设计非常系统，通过大量消融实验证明了各组件的必要性，特别是用数据实证了多被试预训练对单被试解码的正面作用，分析深入。
- **工程实现与资源消耗**：在取得SOTA性能的同时，相比MindEye方法，在参数量、显存占用和推理时间上有明显降低，更高效。

### 8. 不足与局限

- **单被试精化成本高**：虽性能优异，但对每个新个体仍需对整个大型模型进行完整微调，计算成本较高，缺乏轻量化适配方案。
- **跨被试泛化能力未充分探索**：研究主要集中在“个体内”解码。虽然有多被试预训练，但对于完全未见过的“新被试”或新实验范式（跨设备）的直接泛化能力并未验证和讨论。
- **耦合训练与解耦不彻底**：尽管设计了双支路，但高低层网络是联合端到端训练的，未能彻底解耦。这可能是导致某些复杂场景下出现语义混淆（如猫狗不分）或细节缺失（复杂场景元素丢失）等失败案例的原因。
- **脑区覆盖局限**：仅使用特定视觉皮层（VC）区域进行解码，未探索其他潜在相关脑区可能带来的信息增益。

### 9. 结论与未来工作

- **结论**：NeuroPictor通过“校准编码-多被试预训练-单被试精化”的三步框架和高低层双支路调制网络，实现了更精细、准确的fMRI到图像重建，验证了多被试预训练在脑解码中的巨大潜力。
- **未来工作**：探索更高效的单被试适配策略（如Adapter、特殊Token）、提升模型对未见被试的零/少样本泛化能力、开发更好的策略来解耦多级信息、并考虑引入更多脑区信号。
