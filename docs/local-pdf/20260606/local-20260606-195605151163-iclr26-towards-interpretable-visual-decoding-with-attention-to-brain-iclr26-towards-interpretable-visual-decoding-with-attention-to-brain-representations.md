tldr: 现有的视觉解码方法通常先将脑信号映射到中间图像或文本特征空间，再指导生成过程，这模糊了不同脑区对重建的贡献。本文提出NeuroAdapter框架，直接以脑表征为条件控制潜在扩散模型进行端到端重建，并设计图像-大脑双向可解释性框架（IBBI），通过分析去噪过程中的跨注意力模式揭示不同皮层区域如何影响生成轨迹，在公开fMRI数据集上取得了竞争性的重建质量，同时实现了更透明的神经解码。

## 摘要
近期研究显示，利用深度生成模型可从人类大脑活动中解码复杂视觉刺激，这为探究大脑如何表征真实世界场景提供了新途径。然而，许多现有方法先将大脑信号映射到中间图像或文本特征空间，再引导生成过程，这掩盖了不同脑区对最终重建输出的贡献。本文提出 NeuroAdapter，一种视觉解码框架，直接将潜在扩散模型条件化于大脑表征，绕过了中间特征空间的需求。我们的方法在公开功能磁共振成像数据集上展示了与先前工作相媲美的视觉重建质量，同时更透明地揭示大脑信号如何驱动视觉重建。为此，我们引入了一种图像-大脑双向可解释性框架（IBBI），通过分析扩散去噪步骤中的交叉注意力模式，揭示不同皮层区域如何影响展开的生成轨迹。我们的工作突显了端到端脑到图像重建的潜力，并为可解释神经解码铺平了道路。

## Abstract
Recent work has demonstrated that complex visual stimuli can be decoded from human brain activity using deep generative models, offering new ways to probe how the brain represents real-world scenes. However, many existing approaches first map brain signals into intermediate image or text feature spaces before guid- ing the generative process, which obscures the contributions of different brain areas to the final reconstruction output. In this work, we propose NeuroAdapter, a visual decoding framework that directly conditions a latent diffusion model on brain representations, bypassing the need for intermediate feature spaces. Our method demonstrates competitive visual reconstruction quality on public fMRI datasets compared to prior work, while providing greater transparency into how brain signals drive visual reconstruction. To this end, we introduce an Im- age–Brain BI-directional interpretability framework (IBBI) that analyzes cross- attention patterns across diffusion denoising steps to reveal how different corti- cal areas influence the unfolding generative trajectory. Our work highlights the potential of end-to-end brain-to-image reconstruction and establishes a path for interpretable neural decoding.

## 2. 论文提出的方法论
- **核心思想**：提出 **NeuroAdapter** 框架，它是一个端到端模型，完全摒弃了中间图像或文本特征空间，直接将脑信号处理后的表征作为条件注入到潜在扩散模型（Stable Diffusion）的交叉注意力层中，实现“一次成型”的图像重建。
- **关键技术细节**：
  - **神经数据处理与分区 (Parcellation)**：使用 Schaefer 皮层分区方案将高维 fMRI 顶点数据分为左右脑共1000个分区，并选取了其中信噪比（SNR）最高的 $p=200$ 个分区作为模型输入。
  - **分区线性映射 (Parcel-wise Linear Mapping)**：为每个选定的脑分区学习一个唯一的投影矩阵 $w \in \mathbb{R}^{v_{\text{max}} \times f}$，将变长（padding至最大顶点数 $v_{\text{max}}$）的顶点响应向量映射到固定维度 $f$ 的 token 嵌入 $E \in \mathbb{R}^{p \times f}$。
  - **扩散过程与大脑条件化**：采用类似 IP-Adapter 的架构，在 Stable Diffusion 的 UNet中，用新的交叉注意力模块取代原有的文本条件，直接接收 $p$ 个大脑 token 嵌入。训练时，仅更新线性映射器和新增的交叉注意力层，其余参数冻结。
  - **关键正则化策略**：采用了 **fMRI Token Dropout** 技术和 **Min-SNR Loss Weighting** 策略，提升了模型的鲁棒性和训练稳定性。
  - **图像筛选机制**：推理时，对每个测试样本，解码器生成多张候选图像。使用一个独立训练的全脑编码器来预测这些图像对应的 fMRI 活动，选择与真实 fMRI 信号皮尔逊相关系数最高的图像作为最终解码结果。
- **可解释性框架（IBBI）**：
  - **问题设定**：分析每个去噪步 $t$ 的交叉注意力权重矩阵 $A^{(l,h,t)} \in \mathbb{R}^{q \times p}$，它记录了来自UNet中 $q$ 个空间查询（图像特征）与 $p$ 个脑分区 token 间的关联程度。
  - **大脑导向视图 (Brain-directed View)**：通过聚合跨层跨头的注意力权重，计算出每个脑分区在每个去噪步的贡献值 $B_j^{(t)}$，可视化为皮层表面图，展示不同脑区的影响力。
  - **图像导向视图 (Image-directed View)**：对于一组特定的脑区（ROI），如面孔、身体选择性区域，通过聚合和上采样其对应的注意力权重，生成像素级的 **ROI 注意力图**，直接可视化在生成的图像上，展示该脑区在生成图像中“关注”的空间区域。
