## 摘要
生成模型的进步推动了基于文本和图像的多上下文图像生成。脑信号提供了用户意图的直接表征，为图像定制带来了新的机遇。然而，这在脑信号解读、跨模态上下文融合与保留方面面临挑战。在本文中，我们提出MindCustomer，探索在多上下文图像生成中融合视觉脑信号。我们首先设计了共享神经数据增强方法，通过引入图像-大脑转换器（IBT）从视觉图像生成大脑响应，实现稳定的跨被试脑嵌入。然后，我们提出了一种有效的跨模态信息融合流程，在扩散模型中无掩码地自适应融合来自图像和脑上下文的独特语义，解决了上下文保留中的语义冲突，实现了上下文和谐集成。在融合流程中，我们进一步利用IBT将图像上下文转换为大脑表征，以缓解跨模态差异。MindCustomer支持跨被试生成，输出统一、高质量且自然的图像。此外，它通过少样本学习对新被试表现出强大的泛化能力，显示出实际应用的潜力。作为首个将脑信号融入多上下文生成的工作，MindCustomer为未来脑控生成技术奠定了基础性探索与启发。

## 2. 方法论

### 2.1 核心思想

- 利用图像-大脑转换器（IBT）生成跨被试的伪脑信号，缓解真实脑数据稀缺。
- 在预训练的Versatile Diffusion（VD）中构建免掩码的融合流程，通过 **图像上下文微调→脑嵌入优化→嵌入集成** 的顺序，逐步缓解模态差距与语义冲突。

### 2.2 关键技术细节与流程

**（1）脑表征预训练（IBT + 跨被试嵌入器）**

- 训练**Image-Brain Translator** $G_\eta$：将图像CLIP嵌入 $E_I$ 映射为指定被试的伪fMRI体素 $B'$，损失为 $L_{\text{IBT}} = L_{\text{MSE}}(G(E_I, \eta), B')$。
- **跨被试脑嵌入器**：由浅层被试专属嵌入器 $E_{\int}$ 和深层共享嵌入器 $E_{\lceil}$ 组成，将真实与伪体素统一映射到CLIP空间，并用SoftCLIP损失与MSE损失监督。
- 进一步引入ClipCap映射器 $M_\sigma$ 提取语义增强特征，同样用SoftCLIP和MSE监督。

**（2）扩散微调与脑嵌入优化**

- **图像上下文微调**：用IBT将图像上下文 $I$ 转为脑体素 $B_p$，经脑嵌入器得 $e_p$，以标准扩散损失 $L_t^{\text{img}}$ 微调VD，使其学会“脑表征→图像”的映射。
- **脑嵌入优化**：冻结微调后VD，以图像重建为目标，用扩散损失 $L_t^{\text{brain}}$ 对其实脑上下文嵌入 $e_b$ 进行轻量优化（仅修改嵌入，不修改模型），使脑嵌入在语义上靠拢图像上下文，解决直接融合时的冲突。

**（3）多模态嵌入集成**

- 双上下文：直接拼接 $e_p$ 与优化后 $e_b$。
- 三上下文（加文本）：用线性插值 $e_c = (1-\alpha)e_p + \alpha e_b$ 将融合嵌入送入VD的图像流，文本嵌入送入文本流，联合生成。$\alpha \in [0.4, 0.7]$ 时融合效果最佳。

**（4）新被试少样本生成**

- 利用已有被试的共享嵌入器，对新被试仅训练IBT和浅层嵌入器（冻结深层共享部分），结合Reset-Tuning，使用少量数据即可快速适应。

## 3. 实验设计

- **数据集与场景**：
  - 使用NSD数据集（7T fMRI），4名被试（Subj1/2/5/7）的全脑数据，训练集8859张图像，测试集982张共享图像。
  - 场景：跨被试、多上下文（图像+脑信号+文本）的图像生成。
- **评价指标**：
  - **生成质量与语义保留**：CLIP-I、DINOv2（语义相似度）、CLIP-IQA（视觉质量）。
  - **脑解码能力**：PixCorr、SSIM、AlexNet、Inception、CLIP等。
  - **人类偏好**：用户对质量和一致性的1-3分评分。
- **对比方法**：
  - Baseline-1：将脑上下文替换为视觉刺激图像，直接用VD多输入生成。
  - Baseline-2：用SOTA脑解码模型（MindEye）将脑信号重建为图像作为上下文，再用VD融合。
  - 消融实验：移除IBT、微调、优化、ClipCap等组件。

## 4. 资源与算力

- **硬件**：单张Tesla A100 GPU。
- **效率**：单张图像生成时间约6分钟。
- **训练参数**：
  - IBT：200 epochs，学习率 $5\times10^{-5}$，batch size 50。
  - 脑嵌入器：600 epochs，学习率 $3\times10^{-3}$，batch size 50。
  - VD微调：200 epochs，学习率 $5\times10^{-8}$，batch size 1。
  - 脑嵌入优化：100 epochs，学习率 $1\times10^{-5}$，batch size 1。
- **未明确说明**：未提及具体GPU显存占用或总训练时长（小时级）。

## 5. 实验数量与充分性

- **充分程度**：实验数量较为充分，覆盖定性、定量、对比、消融和用户研究。
  1. 跨被试生成可视化（多组图像、多被试）。
  2. 相同刺激下不同被试的生成结果（鲁棒性验证）。
  3. $\alpha$ 插值过程可视化（连贯性验证）。
  4. 不同文本下的多样生成（泛化性）。
  5. 与新基线（Baseline-1/2）的定量对比（CLIP-I、DINOv2、CLIP-IQA）和定性比较。
  6. 用户研究（220份有效评分）。
  7. 新被试少样本生成（10%/20%/40%数据量），含定量指标。
  8. 消融实验（5组剥离组件）与定量评估。
  9. 脑解码性能评估（与MindBridge、UMBRAE对比）及IBT模拟的Pearson相关性分析。
- **客观与公平性**：基线使用相同VD架构，消融实验逐步验证组件贡献，对比公平；但脑解码对比中方法训练细节可能不完全对等，但已尽力公平。

## 6. 主要结论与发现

1. **首次实现**脑信号在多上下文图像生成中的有效融合，无需掩码或多视角输入。
2. **IBT** 能生成语义合理的伪脑信号（平均Pearson相关系数0.426），为跨被试嵌入提供关键数据增强。
3. **微调+优化** 的分步策略有效缓解模态语义冲突，生成图像在语义相似度（DINOv2 0.654）和生成质量（CLIP-IQA 0.892）上显著优于基线。
4. 方法对**新被试少样本泛化**能力突出（40%数据即可接近全量效果），具备实际落地潜力。
5. 脑解码能力亦具竞争力，表明表征预训练阶段有效。

## 7. 优点

- **方法创新性强**：首次将脑信号作为正式上下文源，并提出“图像→脑空间”的跨模态转换器来消除表征差异，思路新颖。
- **流程设计精巧**：分阶段（微调→优化→集成）处理语义冲突，而不是直接端到端融合，避免模态篡改或覆盖。
- **实用性验证全面**：涵盖少样本适应、用户偏好测试、跨被试一致性，与临床应用场景贴合。
- **无掩码、单图像输入**：降低使用门槛，且生成质量高、自然度高。

## 8. 不足与局限

- **脑信号粒度较粗**：fMRI记录的是全局信息，可能难以处理精细属性或局部细节的精确控制。
- **数据依赖性**：仍需依赖NSD等高质量预记录数据集，未讨论在更低信噪比或不同范式脑信号上的表现。
- **生成效率**：单张图6分钟，虽可接受但离实时交互仍有距离。
- **评价维度有限**：未进行更多元的图像编辑任务衡量，如风格化力度、属性解耦度等。
- **伦理与隐私**：论文仅简要提及，未深入讨论脑信号的使用安全与个体隐私保护。
