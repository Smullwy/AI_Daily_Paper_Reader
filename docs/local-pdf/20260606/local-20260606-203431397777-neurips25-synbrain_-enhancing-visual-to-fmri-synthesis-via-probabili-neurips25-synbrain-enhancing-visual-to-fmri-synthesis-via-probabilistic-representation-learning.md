解析视觉刺激如何转化为皮层反应是计算神经科学中的一个基本挑战。这种视觉到神经的映射本质上是一种一对多的关系，因为相同的视觉输入在不同试验、情境和个体之间会可靠地引发多变的血流动力学反应。然而，现有的确定性方法难以同时建模这种生物变异性，并捕捉编码刺激信息的潜在功能一致性。为了解决这些限制，我们提出了SynBrain，一个生成式框架，以概率性和生物学可解释的方式模拟从视觉语义到神经反应的转化过程。SynBrain引入了两个关键组成部分：(i) BrainVAE通过概率学习将神经表征建模为连续概率分布，同时通过视觉语义约束保持功能一致性；(ii) 语义到神经映射器充当语义传输通路，将视觉语义投影到神经反应流形中，以实现高保真的fMRI合成。实验结果表明，SynBrain在特定个体的视觉到fMRI编码性能上超越了现有最先进的方法。此外，SynBrain能够利用少量数据高效地适应新个体，并合成高质量的fMRI信号，这些信号能有效提升数据有限的fMRI到图像解码的性能。除此之外，SynBrain揭示了跨试验和跨个体的功能一致性，其合成的信号捕捉到了由生物神经变异性塑造的可解释模式。我们的代码可在https://github.com/MichaelMaiii/SynBrain获取。

## Abstract
Deciphering how visual stimuli are transformed into cortical responses is a funda- mental challenge in computational neuroscience. This visual-to-neural mapping is inherently a one-to-many relationship, as identical visual inputs reliably evoke variable hemodynamic responses across trials, contexts, and subjects. However, existing deterministic methods struggle to simultaneously model this biological variability while capturing the underlying functional consistency that encodes stimulus information. To address these limitations, we propose SynBrain, a gen- erative framework that simulates the transformation from visual semantics to neural responses in a probabilistic and biologically interpretable manner. Syn- Brain introduces two key components: (i) BrainVAE models neural represen- tations as continuous probability distributions via probabilistic learning while maintaining functional consistency through visual semantic constraints; (ii) A Semantic-to-Neural Mapper acts as a semantic transmission pathway, project- ing visual semantics into the neural response manifold to facilitate high-fidelity fMRI synthesis. Experimental results demonstrate that SynBrain surpasses state- of-the-art methods in subject-specific visual-to-fMRI encoding performance. Fur- thermore, SynBrain adapts efficiently to new subjects with few-shot data and synthesizes high-quality fMRI signals that are effective in improving data-limited fMRI-to-image decoding performance. Beyond that, SynBrain reveals functional consistency across trials and subjects, with synthesized signals capturing inter- pretable patterns shaped by biological neural variability. Our code is available at https://github.com/MichaelMaiii/SynBrain.

## 2. 方法论
### 2.1 总体框架与两阶段训练
- **核心思想**：通过 **BrainVAE**（变分自编码器）学习 fMRI 的连续概率潜在空间，并利用 **语义到神经映射器（S2N Mapper）** 将 CLIP 视觉嵌入直接映射到该潜在空间的分布参数。
- **推理流程**：输入图像 → 冻结的 CLIP 编码器 → S2N Mapper → BrainVAE 解码器 → 合成 fMRI。

### 2.2 BrainVAE：语义条件化的概率神经表征
- **动机**：MLP 自编码器（如 MindSimulator）无法有效建模空间局部性与长程依赖，MLP‑VAE 训练不稳定（图 3）。BrainVAE 使用 **1D卷积 + 注意力** 的多分辨率编码器‑解码器，显著提高重建稳定性和语义表达能力。
- **架构关键点**：
  - 编码器输出 $ \mu, \log\sigma^2 $，通过重参数化采样得到潜在向量 $z$。
  - 解码器重建 fMRI 信号 $ \hat{y}_{\text{fMRI}} = D(z)$。
- **训练目标**：
  $$L_{\text{BrainVAE}} = \| D(z) - y_{\text{fMRI}} \|_2^2 + \lambda_{\text{KL}} D_{\text{KL}}(q(z|y_{\text{fMRI}}) \| \mathcal{N}(0,I)) + \lambda_{\text{CLIP}} \text{SoftCLIP}(z, z_{\text{CLIP}})$$
  - 第一项保证体素级重建保真度；第二项正则化潜在空间；第三项通过 SoftCLIP 损失将 fMRI 潜在嵌入与图片 CLIP 嵌入对齐，注入视觉语义。

### 2.3 S2N Mapper：点‑分布语义映射
- **设计**：轻量 Transformer 模块 $f_{\text{S2N}} : z_{\text{CLIP}} \mapsto z_{\text{align}}$，直接将 CLIP 视觉嵌入投射到 BrainVAE 编码器的输出空间 $z$（即后验均值的近似）。
- **训练目标**：$$L_{\text{S2N}} = \text{MSE}(f_{\text{S2N}}(z_{\text{CLIP}}), z)$$
- **优势**：相比于扩散先验（如 DiT）的多步去噪，S2N 实现 **一步映射**，消除训练‑推理分布偏移，无需手工先验或多次采样后筛选。

### 2.4 推理与采样
- 测试时，由 S2N Mapper 预测分布中心 $z_{\text{align}}$，可直接解码（对应 $nf=0$）或加入缩放高斯噪声再解码，实现 **可控的多样化合成**。

## 3. 实验设计
### 3.1 数据集与场景
- **数据集**：自然场景数据集 **NSD**，使用其中完成全部扫描的 4 名被试（Sub‑1, Sub‑2, Sub‑5, Sub‑7）的 7T fMRI 数据，训练集 9,000 张图像（27,000 试次），测试集 1,000 张图像（每张 3 试次）。
### 3.2 评估基准与对应方法
- **被试内视觉→fMRI 合成**：与 **MindSimulator**（确定性自动编码器 + 扩散映射）对比。
- **跨被试少样本适应**：仅用 1 小时新被试数据微调，评估合成信号的体素精度和语义一致性。
- **用于 fMRI‑to‑图像解码的数据增强**：在少样本解码设定下，用合成 fMRI 扩充训练集，与 **MindEye2**（1 h）、**MindAligner**（1 h）对比解码性能。
- **消融研究**：依次移除变分采样、对比学习、S2N Mapper，验证各模块作用。
- **附加实验**：不同视觉编码器（MAE、DINOv2）、不同潜在维度、不同 Transformer 层数、与扩散 Transformer（BrainVAE‑DiT）的对比、反向被试适应、额外被试（Sub3,4,6,8）、不同合成数据量等。

### 3.3 评估指标
- **体素级**：MSE、Pearson 相关系数、余弦相似度。
- **语义级（通过预训练 fMRI‑to‑图像解码器 MindEye2 的解码图像评估）**：Inception Score (Incep)、CLIP 相似度、EfficientNet 距离、SwAV 距离。
- **图像检索**：fMRI 嵌入与对应图片 CLIP 嵌入的 Top‑1 检索准确率（原始 fMRI 与合成 fMRI 分别评估）。

## 6. 主要结论与发现
- SynBrain 在被试内视觉→fMRI 合成上 **显著优于** MindSimulator，且仅需单次生成（不需要多试次采样与后选）。
- 合成 fMRI 的语义质量甚至超过原始 fMRI（检索准确率 92.5% vs. 84.8%），表明模型能蒸馏出与视觉语义高度相关的成分。
- 仅用 1 小时目标被试数据，SynBrain 即可适应并合成保持语义一致性的 fMRI，且合成信号在数据增强后可提升少样本 fMRI‑to‑图像解码性能（超越 MindAligner）。
- 功能一致性分析显示，合成信号保留了 **类别选择性区域的稳定激活模式**，即使在试次间及被试间变异下，高层语义表征仍保持稳定。

## 7. 优点
- **概率建模解决了视觉→神经的一对多本质**，而非仅靠注入噪声或采样平均。
- **一步语义‑神经映射**（S2N Mapper）比扩散先验更稳定、高效，避免分布偏移。
- 架构设计（卷积+注意力）针对 fMRI 空间特性优化，显著提升训练稳定性和表示质量。
- 实验设计全面，从合成性能到下游解码与神经生物合理性分析，形成闭环验证。
- **强跨被试迁移能力**：极少量数据即可适应新个体，且支持双向迁移。

## 8. 不足与局限
- **依赖预训练视觉模型**（CLIP），可能引入视觉表征偏差，不完全贴合真实神经加工。
- 当前模型仅建模 **空间响应模式**，未整合时间动态信息（如 BOLD 时间序列）。
- 未明确建模注意状态、神经调制等更多变异来源，概率先验仍较简化。
- 合成数据虽总体有益，但随合成数据量增加增益趋缓甚至下降，表明合成分布与真实分布仍存在差距，且可能冲淡个体差异细节。
- 实验仅基于 NSD 自然图片数据集，对其他类刺激（如情感面孔、人工纹理）的泛化性未检验。
